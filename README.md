# InvoiceMint 📊

InvoiceMint is a modern SaaS application for creating and managing invoices, built with Next.js 15. Create, manage, and send professional invoices with ease.

## ✨ Features

- 🔐 Secure authentication with NextAuth
- 📝 Create and manage invoices
- 📧 Automated email notifications
- 💾 PDF generation and download
- 📱 Responsive design
- 🎨 Modern UI with shadcn/ui
- 🔍 Type-safe forms with Conform and Zod
- 🗄️ PostgreSQL database with Neon

## 🚀 Tech Stack

- **Framework:** Next.js 15
- **Authentication:** NextAuth
- **Database:** Neon (PostgreSQL)
- **ORM:** Prisma
- **Styling:** Tailwind CSS + shadcn/ui
- **Form Handling:** Conform + Zod
- **PDF Generation:** jsPDF
- **Email Service:** Mailtrap
- **Language:** TypeScript

## 📋 Prerequisites

Before you begin, ensure you have:

- Node.js 18+ installed
- A Neon database instance
- A Mailtrap account
- Git installed
